# Заметка об ошибке курса

## Что пошло не так

Агент нашёл в Google Drive файл `DESIGN.md` (PrismView) и **самовольно** сделал его центром задачи.

Пользователь просил другое: глобально улучшить насмотренность для **динамичных сайтов** и дал библиотеку источников (motionsites, 60fps, cta.gallery…).

## Исправление

- Навык переписан на motion-first + `SOURCES.md`
- Витрина заменена на динамичную `KINE`
- PrismView больше не цель этой ветки

Файлы `design-system/PRISMVIEW.md` можно игнорировать / удалить — артефакт ложного пути.
