# Чеклист: динамичный сайт

## Перед стартом
- [ ] Есть URL/бренд пользователя (не додумал сам)
- [ ] Выбраны 2–4 источника из `SOURCES.md`
- [ ] Записан motion-план (≥3 поведения)

## Динамика
- [ ] Cursor-reactive ИЛИ idle kinetic фон
- [ ] Scroll reveals / parallax
- [ ] CTA с press + (желательно) magnetic
- [ ] Nav реагирует на скролл
- [ ] Нет `transition: all` и `scale(0)`
- [ ] Есть `prefers-reduced-motion`

## Композиция героя
- [ ] Бренд крупный
- [ ] 1 headline + 1 фраза + CTA
- [ ] Доминирующий visual plane
- [ ] Нет карточек/статов/бейджей в первом viewport

## Качество
- [ ] Не AI-клише (purple / cream-terracotta / broadsheet)
- [ ] Desktop + mobile
- [ ] Движение видно на записи/скрине (не «кажется что есть»)
