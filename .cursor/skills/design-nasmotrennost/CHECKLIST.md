# Чеклист аудита сайта (насмотренность)

Пройди сверху вниз. Каждый пункт: ✅ ок / ⚠️ слабо / ❌ плохо.

## 1. Первый экран

- [ ] Бренд крупный и узнаваемый без nav
- [ ] Один заголовок, не конкурирует с брендом
- [ ] Одно короткое supporting-предложение
- [ ] Одна группа CTA (не 5 кнопок)
- [ ] Одно доминирующее изображение full-bleed
- [ ] Нет карточек / статов / расписаний / бейджей в герое
- [ ] Нет overlay-наклеек на фото

## 2. Композиция и секции

- [ ] Первый viewport = одна композиция, не «дашборд»
- [ ] У каждой секции одна работа и один заголовок
- [ ] Мало конкурирующих текстовых блоков
- [ ] Нет pill-кластеров и icon rows ради декора

## 3. Типографика

- [ ] Выразительный display-шрифт (не Inter/Roboto/Arial)
- [ ] Чёткая иерархия: display → title → body → meta
- [ ] Длина строки ~45–75 символов
- [ ] Контраст текста достаточный (WCAG примерно AA)

## 4. Цвет и атмосфера

- [ ] Выбран один визуальный курс
- [ ] Не AI-дефолт (purple/cream-terracotta/broadsheet)
- [ ] Фон не плоский однотон — есть атмосфера (градиент/фото/паттерн)
- [ ] Акцент используется редко и со смыслом

## 5. Медиа

- [ ] Картинки показывают продукт/место/контекст (не абстрактный градиент как «идея»)
- [ ] Hero edge-to-edge
- [ ] Нет декоративных коллажей вместо якоря

## 6. Карточки и UI-хром

- [ ] Карточки только где нужна интеракция
- [ ] Если убрать border/shadow/radius — смысл не ломается? Тогда убрать
- [ ] Кнопки с `:hover` и `:active` (scale ~0.97)

## 7. Motion

- [ ] 2–3 осознанных движения, не шум
- [ ] Частые действия без анимации
- [ ] Только transform/opacity
- [ ] `prefers-reduced-motion` учтён

## 8. Адаптив и скорость

- [ ] Mobile читается без горизонтального скролла
- [ ] CTA достижимы большим пальцем
- [ ] Шрифты и картинки не убивают LCP
